# ▶️ YouTube Login Page – React Project

## 📌 Project Overview

The **YouTube Login Page** is a front-end development mini-project created using React.js and CSS. The project recreates a YouTube-inspired login interface with username and password sections, a Remember Me checkbox, a Forgot Password option, and a Log In button.

The design includes a background image, a centered login form, and a transparent glass-style panel to create an attractive user interface.

## 🎯 Objectives

- Develop a login page using React.js.
- Apply CSS styling to create a YouTube-inspired interface.
- Understand React functional components.
- Design form elements and interactive UI controls.
- Practice component-based front-end development.

## 🛠️ Technologies Used

- **React.js** – Building the user interface.
- **JavaScript** – Component logic.
- **CSS3** – Styling, layout, background, and visual effects.
- **HTML / JSX** – Structuring webpage elements.

## ✨ Features

- YouTube-inspired login page design.
- Username and password sections.
- Remember Me checkbox.
- Forgot Password option.
- Log In button with custom styling.
- Sign Up text for new users.
- Background image support.
- Glassmorphism-style form with a transparent background and blur effect.
- Responsive styling can be added for different screen sizes.

## ⚙️ How to Run the Project

1. Install [Node.js](https://nodejs.org/).
2. Create or open your React project folder.
3. Install the project dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

**Note:** The `npm run dev` command applies to Vite-based React projects. For other setups, use the appropriate start command.

## 🔒 Limitations

This project demonstrates a **front-end interface only**. The provided source does not implement actual user authentication, password verification, account creation, or password recovery. The interface should not be used to collect real login credentials without a secure backend and appropriate authentication mechanisms.

## 📝 Conclusion

The YouTube Login Page mini-project demonstrates how React.js and CSS can be used to develop an attractive login interface. It provides practical experience with JSX, functional components, form layout, CSS styling, background images, and glassmorphism effects.

The project builds a foundation for developing more advanced web applications with functional authentication and responsive user interfaces.
